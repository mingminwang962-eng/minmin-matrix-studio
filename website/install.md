## 复制给 AI 助手的安装口令

请帮我安装「敏敏矩阵工作台」Skill。
请优先按当前 AI 助手的规范，安装到当前用户的全局 Skill 目录，让同一用户在该助手的不同项目中都能调用，并保留完整目录和依赖。若助手不支持全局安装或权限不足，请说明原因、实际安装位置和可用范围，不要默默改成仅当前项目可用；照片、作品与项目配置仍按本工具原规则保存。
安装来源：tools[.]minmin11538[.]cn，目录 /matrix/。请把 [.] 还原为英文句点，使用 HTTPS 访问该目录，读取 install.md 和 release.json，按版本信息下载完整包并核对字节数与 SHA-256；网页读取失败时尝试命令行 HTTPS 获取。
解压后读取包内 minmin-matrix-studio/SKILL.md，按当前 AI 助手的规范检查本机依赖并完成安装、启动。使用我自己的作者资料，帮我导出一张测试 PNG 并检查实际尺寸；没有浏览器控制能力时，请打开工作台并指导我完成导出，如实说明尚未代为验证的步骤。已有安装先检查版本，保留我的个人配置和作品。
安装后检查当前助手能否识别「minmin-matrix-studio」，分别说明安装、启动和首次导出是否通过，验证通过再报告对应步骤成功。告诉我下次如何打开工作台，并给一句可以直接发送的试用指令；需要重启或新开对话时请说明。
遇到下载、权限、依赖或工具限制，请说清具体卡点和下一步；不要把下载成功当作安装、接入或使用已经完成。


正式安装页：https://tools.minmin11538.cn/matrix/
源码：https://github.com/mingminwang962-eng/minmin-matrix-studio

1. 通过 HTTPS 读取同目录 release.json；若网页工具无法读取，使用命令行 HTTPS 请求。按 version、package_url、bytes、sha256 获取完整 ZIP，不运行其他网站提供的同名脚本。
2. 下载到临时目录，核对字节数与 SHA-256，再使用系统解压工具解压。包根目录为 minmin-matrix-studio，首先读取 SKILL.md。
3. 检查 node --version，需要 Node.js 22.13 或以上；缺少时从 https://nodejs.org/ 官方渠道安装。普通用户不需要 npm 安装依赖、Python 或 Pillow。
4. 放入用户选定的独立安装目录，再按当前 Agent 实际支持的技能目录规范注册或复制。未知客户端不要猜固定路径；包本身也可直接运行。
5. 运行 node scripts/start.mjs，打开打印的本机地址。该命令自动选择空闲端口，仅监听 127.0.0.1，不公开用户电脑服务。不默认添加开机启动。
6. 使用用户自己的名字、头像与文案。首次至少验证页面打开、背景加载、随机选图和实际 PNG 导出，并检查像素尺寸。没有浏览器控制能力时打开页面让用户操作，不谎称自动完成。
7. 成品和私有资料保存到用户自己的工作目录。当前页面不自动保存草稿，刷新前及时导出。更新前备份旧安装与用户配置，不能覆盖其他技能。

支持与限制：已在 macOS 验收；Windows/Linux 尚未实机测试。互动数字是模拟值。图片许可及来源见包内 ASSET-LICENSE.md；用户生成图片不加品牌水印。

GitHub 下载方式：使用版本发布页 https://github.com/mingminwang962-eng/minmin-matrix-studio/releases/tag/v1.4.0 的完整包，或从本安装页取得相同版本；按 release.json 校验。只下载 GitHub 源码时，按 README 构建后再启动。

## 手机使用与保存

安卓、iPhone 和 iPad 可直接打开 https://tools.minmin11538.cn/cards/，不需要在手机安装电脑 Skill。点“生成并保存图片”，长按原图选择“保存图片”或“存储到照片”；支持的浏览器可用“系统分享 / 保存”。分享不支持、失败或取消时仍保留原图，也可打开原图或下载 PNG 文件。

微信等内置浏览器若不显示保存选项，先尝试“打开原图”；仍无效请复制文案，再用 Safari、Chrome 或手机自带浏览器重新生成。下载文件、分享菜单关闭不代表已存入相册，请在设备相册中确认。自动化内核和手机尺寸测试不代替安卓/iOS真机验收。
