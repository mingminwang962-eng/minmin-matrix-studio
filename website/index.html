什么样的 Agent 可以用？

需要能下载文件和执行本机命令。自动填写与点击导出还需要浏览器控制能力；没有该能力时，可以由 Agent 启动，再由你在网页里编辑。首版已在 macOS 验证完整包独立启动和 PNG 导出，Windows/Linux 尚未实机验证。

安卓和 iPhone 怎么保存到相册？

手机打开在线工作台，点“生成并保存图片”后长按原图，选择“保存图片”或“存储到照片”。支持时可点“系统分享 / 保存”；分享不可用或取消后，原图仍可保存。也可打开原图或下载 PNG 文件。微信等内置浏览器若没有保存选项，先试打开原图，仍无效则复制文案后用系统浏览器重新生成。请在相册中确认结果，网页不能跳过系统确认直接写入相册。

我的文案和头像会传到哪里？

本地上传的头像、背景与编辑文字在浏览器处理，应用没有保存文案的接口。使用网络图片时会请求对应图片来源。当前不自动保存草稿，刷新前请及时导出。

互动数字是真实数据吗？

不是。它们是可修改的模拟展示值，不读取平台后台，不表示实际点赞、评论或浏览量。

图片从哪里来？

本版仅带 254 张敏敏委托 imagegen 生成、记录完整的底图，不含上游原有图库。图片使用说明和逐张来源见 素材来源。
