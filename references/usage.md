# 使用与来源

分享版默认作者为“你的名字”，账号留空，中性头像。产品名称保留敏敏矩阵工作台。作者资料在页面设置，成品保存到用户指定目录；不要把用户私人文案写回共享技能目录。

完整包已构建好，只需要 Node 22.13+。内置图库与本地上传不需要模型 API key；首次下载需要联网，网络图片会访问相应来源。当前不自动保存编辑内容，不提供自动发帖或文案采集。

图库只含敏敏委托 imagegen 生成的 254 张底图。按场景和关键词筛选，“随机一张”只从当前筛选结果中选择，尽量避免重复当前背景。每页 12 张，可直接跳页；下一页缩略图提前缓存。选图先完成解码再切换，避免出现空白画布。

代码及原作者声明见 ../LICENSE，图片使用与出处见 ../ASSET-LICENSE.md，第三方依赖见 ../THIRD_PARTY_NOTICES.md。发布地址 https://tools.minmin11538.cn/matrix/ ，源码 https://github.com/mingminwang962-eng/minmin-matrix-studio 。

## 手机保存图片

手机直接打开在线工作台，无需安装电脑 Skill。生成后长按完整 PNG，按浏览器菜单保存；支持时也能通过“系统分享 / 保存”操作。系统分享不可用、失败或取消时，原图和“打开原图”“下载 PNG 文件”仍可使用。文件下载目录与相册不是同一验收结果；保存完成请到手机相册确认。

安卓、iPhone、iPad 和微信等内置浏览器按实际浏览器能力显示入口。没有保存菜单时，先打开原图；仍不可用则复制文案，在 Safari、Chrome 或手机自带浏览器重新打开在线版并生成。电脑本地版继续只监听本机，不能直接用手机访问电脑的 127.0.0.1。
